The problem

Parking is still run on paper and memory.

Small and mid-sized parking lots lose money and time every day, and drivers waste time looking for a free slot.

Today

  • Nobody knows how many slots are free until a car drives in
  • Two staff members can park two cars in the same slot
  • Fees are calculated by hand, so mistakes and disputes happen
  • Drivers cannot reserve a slot before they travel
  • Owners have no clear record of daily income or occupancy

With ParkEase

  • A live floor plan shows every slot, updated in real time
  • The database blocks double parking and double booking
  • The server calculates every fee, with a printed receipt
  • Drivers book a time window and pay in advance
  • History, payments and CSV export give a clear daily picture
What it does

Everything a parking lot needs, in one place.

Built for the people who run the lot and for the people who park in it.

Visual layout designer

Draw slots, roads, gates and arrows on a floor. Save a draft, then publish to create the real slots. Bulk naming (A01, A02...) included.

Number plate entry

Capture a plate from a photo or camera. The system reads it in the browser, staff verify it, and the slot is claimed in one safe step.

Automatic billing

Hourly or fixed rates, grace period, and part hours rounded up. The amount is always recalculated on the server, so it cannot be changed from the browser.

Live availability

Every change pushes an update through Socket.IO. Managers see the floor change instantly, and the public page shows free counts without any login.

Driver bookings Live

Drivers pick a date, start time and duration, save their vehicles, and book a slot. Unpaid bookings hold the slot for 15 minutes, then release it.

Secure by design Live

Role-based access, rate-limited login, hashed passwords, consent and account deletion, and privacy-first data retention.

Reports Next

Occupancy trends, revenue by payment method, peak hours, and PDF or Excel exports for any date range.

Online payments Next

Razorpay checkout, verified webhooks, and real refunds for cancelled bookings. A demo payment flow is already working.

Works in any browser

A responsive web app that runs on phones, tablets and desktops. No app store install needed for drivers or staff.

How it works

From setup to first booking in four steps.

The operator sets the lot up once. After that, the system runs the daily work.

Set up the facility

Add the lot, its floors, opening hours and pricing rule.

Draw the layout

Place slots, roads and gates on the canvas. Publish to create live slots.

Park and bill

Staff record entry by plate. On exit the server bills the stay and prints a receipt.

Drivers book ahead

Drivers reserve a slot for a time window, pay, and arrive to a ready space.

Under the hood

Built on a modern, proven stack.

Every part is open, standard and easy to extend.

React + Vite

Fast, responsive interface with React Konva for the floor designer.

Node.js + Express

REST API with role checks, validation, and rate limits.

Cloud database. Slot claims and double-booking rules are enforced in the database.

Live updates for staff and for the public availability page.

Number plate reading that runs in the browser, so plates are not sent to a third party.

Hosted with automatic deploys from Git. Easy to scale when traffic grows.

FAQ

Questions people ask.

Does a driver need to install an app?

No. The driver portal runs in any modern mobile browser. Drivers sign up with an email and password.

What stops two cars from taking the same slot?

The slot is claimed in a single database operation that succeeds only if the slot is still free. Bookings use a 30-minute lock per slot, enforced by a unique database index, so two bookings cannot overlap.

Is the amount on the receipt trustworthy?

Yes. The fee is calculated on the server from the lot's rate rules. The browser only displays it.

What happens if a driver does not pay for a booking?

The slot is held for 15 minutes. If payment is not completed in that time, the slot is released automatically.

How is personal data handled?

Drivers accept a privacy policy at sign-up. They can download their data and delete their account. Old parking records have owner details removed after the retention period.

Can a lot run without internet?

Not today. The system is cloud-based, so an internet connection is needed. Offline mode is not planned for the current phases.
